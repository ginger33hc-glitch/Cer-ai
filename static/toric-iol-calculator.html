Toric need, model and axis in the cataract workflowKatarakt iş akışında torik gereksinim, model ve aks

CER-AI first assesses whether regular corneal astigmatism supports a toric route. After the surgeon chooses a lens family, the embedded toric IOL calculator can present a toric model candidate, marker axis and predicted residual astigmatism when all required inputs are complete. This calculator is a test-only prototype requiring independent manufacturer verification.

Inputs and outputs remain visible

  • Defined anterior and posterior corneal measurements from the required Pentacam sources
  • Surgeon-specific incision location and surgically induced astigmatism (SIA)
  • Lens-family data selected by the surgeon
  • Toric model candidate, implantation marker axis, and predicted residual astigmatism
  • Direct requirement for independent manufacturer-calculator verification
TEST ONLY — NOT CLINICALLY VALIDATED: The embedded CER-AI toric optical model is a prototype for surgeon testing. Do not use its output as the sole basis for implantation. Recheck every source value, available lens model, power, axis, SIA, and predicted residual result with the selected manufacturer’s validated calculator and current instructions for use.
