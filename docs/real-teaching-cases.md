# Anonymized real teaching cases

The public learning center uses three real archived refractive cases (PASS, PASS WITH CAUTION, STOP-DEFER) and one real archived IOL output example. `education_real_cases.json` contains selected saved findings in English and Turkish; it contains no clinical archive IDs. No scoring or treatment code is changed.

Each refractive case has the matching five Pentacam source photographs. Identity panels, examination dates and desktop/file-name strips were permanently removed in raster pixels; public copies were re-encoded without EXIF. Charts were not regenerated. The protected clinical originals are unchanged.

The IOL PDF has real PDF redactions applied to identity and date text, and metadata removed. Its original clinical values and TEST ONLY / independent-verification warnings remain. The archive UI did not expose IOLMaster source images for this entry; the page explicitly identifies it as an output example, not an input file.

The summaries are selected historical findings, not complete original reports, new analyses, external validation or postoperative outcome evidence. No patient identifiers, original filenames, private source-to-case mapping or credentials belong in this repository.

Validation includes bilingual routing and asset responses, removal of synthetic case routes, preservation of eye-specific decisions, PDF text/attachment inspection, image EXIF inspection, OCR screening and visual inspection of redactions. Public asset changes need the same privacy review before publication.
